Política de Privacidade

Última atualização: Novembro de 2025

Compromisso com a Privacidade: O Anglivery está comprometido em proteger a privacidade e os dados pessoais de todos os usuários, clientes e funcionários cadastrados no sistema, em conformidade com a Lei Geral de Proteção de Dados (LGPD - Lei nº 13.709/2018).

1. Informações que Coletamos

O Anglivery coleta e processa as seguintes categorias de dados:

Dados de Usuários do Sistema:

  • Nome completo e credenciais de login
  • Endereço de e-mail
  • Senha criptografada
  • Permissões e nível de acesso
  • Histórico de atividades no sistema

Dados de Clientes Cadastrados:

  • Nome completo
  • CPF (formatado e validado)
  • Telefone de contato (formatado)
  • Endereço completo (para extensão de delivery)
  • Histórico de compras e preferências

Dados de Funcionários:

  • Nome completo e cargo
  • Data de admissão
  • Registro de vendas realizadas
  • Controle de ponto (extensão paga)
  • Informações de salário e benefícios (extensão paga)

Dados de Operação Comercial:

  • Informações de produtos e estoque
  • Registros de vendas e transações
  • Dados de fornecedores
  • Relatórios financeiros e métricas
  • Logs de acesso e uso do sistema

2. Como Utilizamos os Dados

Os dados coletados são utilizados exclusivamente para as seguintes finalidades:

  • Operação do Sistema: Processar vendas, gerenciar estoque, controlar acessos e gerar relatórios
  • Gestão Comercial: Manter histórico de transações, analisar performance e otimizar processos
  • Personalização: Salvar preferências de interface e configurações por usuário
  • Sincronização: Atualizar dados em tempo real entre dispositivos e pontos de venda
  • Segurança: Autenticar usuários, controlar permissões e prevenir acessos não autorizados
  • Conformidade Legal: Cumprir obrigações fiscais, trabalhistas e regulatórias

3. Armazenamento e Proteção de Dados

O Anglivery implementa rigorosas medidas de segurança para proteger seus dados:

Medidas Técnicas:

  • Criptografia: Todas as senhas são criptografadas usando algoritmos seguros
  • Armazenamento na Nuvem: Dados salvos em servidores seguros com backup automático
  • Controle de Acesso: Sistema baseado em permissões e cargos hierárquicos
  • Validação de Dados: Verificação de integridade e formato de informações
  • Logs de Auditoria: Registro de todas as operações críticas
  • Recuperação: Sistema de backup e recuperação de falhas

Medidas Organizacionais:

  • Acesso restrito aos dados apenas para finalidades específicas
  • Treinamento de equipe sobre privacidade e segurança
  • Monitoramento contínuo de segurança
  • Políticas de retenção e exclusão de dados

4. Compartilhamento de Dados

O Anglivery não vende, aluga ou compartilha dados pessoais com terceiros, exceto nas seguintes situações:

  • Obrigação Legal: Quando exigido por lei, ordem judicial ou autoridade competente
  • Proteção de Direitos: Para proteger direitos, propriedade ou segurança do Anglivery e seus usuários
  • Extensões Especializadas: Alguns dados podem ser processados por módulos específicos, sempre dentro do sistema

Não utilizamos serviços de terceiros para armazenamento ou processamento de dados sem garantias adequadas de proteção.

5. Retenção de Dados

Os dados são mantidos pelo seguinte período:

  • Dados de Usuários Ativos: Durante todo o período de uso da conta
  • Dados de Clientes: Enquanto houver relacionamento comercial ativo
  • Dados Financeiros: Pelo prazo legal exigido pela legislação fiscal (mínimo 5 anos)
  • Logs de Sistema: Por até 12 meses para fins de segurança e auditoria
  • Dados de Contas Encerradas: Anonimizados após 30 dias, mantendo apenas histórico financeiro obrigatório

6. Direitos dos Titulares de Dados (LGPD)

De acordo com a LGPD, você possui os seguintes direitos sobre seus dados pessoais:

  • Acesso: Confirmar se seus dados estão sendo tratados e acessá-los
  • Correção: Solicitar correção de dados incompletos, inexatos ou desatualizados
  • Anonimização: Solicitar anonimização de dados desnecessários
  • Portabilidade: Receber seus dados em formato estruturado e interoperável
  • Eliminação: Solicitar eliminação de dados tratados com seu consentimento
  • Revogação: Revogar consentimento a qualquer momento
  • Oposição: Opor-se ao tratamento em situações específicas

Como Exercer Seus Direitos: Para exercer qualquer um desses direitos, entre em contato através dos canais disponíveis no Anglivery. Responderemos sua solicitação em até 15 dias úteis.

7. Dados de Menores de Idade

O Anglivery não coleta intencionalmente dados de menores de 18 anos. Se um usuário cadastrar um cliente menor de idade, é responsabilidade do usuário garantir que possui autorização do responsável legal.

8. Cookies e Tecnologias Similares

O Anglivery utiliza tecnologias de armazenamento local para:

  • Manter sessão de login ativa
  • Salvar preferências de interface
  • Armazenar cache de dados para melhor performance
  • Sincronizar informações entre dispositivos

Essas tecnologias não rastreiam atividades fora do sistema Anglivery.

9. Sincronização e Dispositivos Múltiplos

O Anglivery permite sincronização bidirecional de dados entre diferentes dispositivos e pontos de venda. Isso significa que:

  • Dados são atualizados em tempo real em todos os terminais
  • Cada dispositivo conectado tem acesso às informações conforme permissões do usuário
  • A troca de equipamento não resulta em perda de dados, pois tudo está na nuvem
  • Você pode desconectar dispositivos a qualquer momento

10. Extensões Pagas e Dados Adicionais

As extensões especializadas podem processar dados adicionais específicos:

  • Concessionárias: Dados de veículos, chassi, documentação
  • Delivery: Endereços, rotas, dados de entregadores
  • Gestão de Funcionários: Ponto, salários, benefícios

Estes dados adicionais seguem as mesmas políticas de proteção e privacidade do módulo central.

11. Notificação de Incidentes

Em caso de incidente de segurança que possa comprometer dados pessoais, o Anglivery se compromete a:

  • Notificar a Autoridade Nacional de Proteção de Dados (ANPD) em até 48 horas
  • Informar os usuários afetados através dos meios de contato cadastrados
  • Tomar medidas imediatas para mitigar danos
  • Investigar e documentar o incidente

12. Transferência Internacional de Dados

Atualmente, o Anglivery armazena todos os dados em servidores localizados no Brasil. Caso haja necessidade de transferência internacional de dados no futuro, você será notificado previamente e solicitaremos seu consentimento explícito.

13. Alterações nesta Política

Esta Política de Privacidade pode ser atualizada periodicamente para refletir mudanças em nossas práticas ou requisitos legais. Você será notificado sobre alterações significativas através do sistema. Recomendamos revisar esta política regularmente.

14. Base Legal para Tratamento

O tratamento de dados pessoais no Anglivery é fundamentado nas seguintes bases legais da LGPD:

  • Execução de Contrato: Necessário para operação do sistema
  • Legítimo Interesse: Para melhorias, segurança e prevenção de fraudes
  • Obrigação Legal: Cumprimento de obrigações fiscais e trabalhistas
  • Consentimento: Para funcionalidades opcionais e extensões especializadas

15. Encarregado de Dados (DPO)

Para questões relacionadas à proteção de dados pessoais, entre em contato com nosso Encarregado de Dados através dos canais disponíveis na página principal do Anglivery.

16. Contato

Para dúvidas sobre esta Política de Privacidade, exercício de direitos ou questões relacionadas a dados pessoais:

  • Acesse a seção de contato no Anglivery
  • Utilize os canais de suporte disponíveis no sistema
  • Envie solicitação formal através do painel de configurações
